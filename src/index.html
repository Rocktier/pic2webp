为什么要用 WebP？

  • Google 开发的现代图片格式
  • 同等画质体积减少 25-50%
  • 支持透明通道，替代 PNG
  • Chrome / Edge / Firefox / Safari 全兼容

如何实现？

  • 内置 WebP 编码引擎，无需安装任何工具
  • 可选 jpegoptim / pngquant 预压缩，进一步减小体积
  • 所有处理本地完成，不上传任何文件
  • 转换后自动统计节省空间

批量处理提示

  • 逐张串行转换，批量拖入不会卡顿
  • 单张建议 < 100MB，超大会占用较多内存
  • 建议单次不超过 200 张，更多请分批处理
